# Fsdb 0.1.3

This stable patch release extends correlated count planning for nullable
columns. It contains the .NET 10 F# library; the MySQL-protocol CLI remains
a separate project.

## Changes since 0.1.2

- Precompute ungrouped correlated `COUNT(nullable_column)` membership in
  `HAVING` predicates, including nullable columns from joined tables.
- Extend the precomputed path to grouped queries with a fixed key, including
  joined nullable counts and mixed nullable and matched-row counts.
- Keep the ordinary executor for shapes that do not meet the planner's exact
  key and fixed-group requirements.

The focused cases were compared with MySQL 8.4.11, and the 3,932-test suite,
package consumer, and CI passed on the release source. Other compatibility
gaps remain in `GAPS.md`. In particular, conversion-warning cardinality in
some correlated `COUNT` queries is still under investigation; query results
match the tested MySQL cases, but `SHOW WARNINGS` can differ.

For durable databases, back up a stopped data directory and test the new
version against a copy before upgrading. Cross-version migration and
downgrade compatibility are not yet guaranteed.
