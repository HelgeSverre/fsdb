# Fsdb 0.1.0

This is the first stable NuGet package version of Fsdb for .NET 10, following
`0.1.0-preview.50`. The package contains the F# embedding library; the
command-line MySQL-protocol server remains a separate project.

## Changes since preview.50

- Correlated `COUNT(*)` and `EXISTS` queries use more indexed and grouped
  plans, including joined equality tuples, exact decimal keys, nullable
  `<=>` keys, and several `HAVING` forms.
- Complex joined views retain writable physical targets beside windowed,
  DISTINCT, recursive, and set-operation read sources. More joined-view
  updates acquire the required source locks and rebase after concurrent
  writes.
- CJK compatibility expanded through supplementary kana and ideographs,
  including exact legacy weights across planes two and three. Japanese
  kana-sensitive ordering and indexed ranges now match the audited MySQL
  corpus at ngram sizes 1–10.
- Geographic distance and relation handling received additional edge-case
  corrections and MySQL differential coverage.

The release was checked against the pinned MySQL 8.4.11 oracle, the F# test
suite, and an isolated consumer that restores the package rather than
referencing the source project.

## Scope and upgrades

Fsdb targets MySQL compatibility for its supported SQL surface; it does not
claim complete MySQL parity. See [GAPS.md](https://github.com/HelgeSverre/fsdb/blob/main/GAPS.md)
for the current coverage and remaining differences. In particular,
general cost-based planning, concurrent writer throughput, geographic
line/polygon overlays, and exact Japanese `WEIGHT_STRING` bytes remain open.

For durable databases, back up a stopped data directory and test the new
version against a copy before upgrading. Cross-version migration and
downgrade compatibility are not yet guaranteed; the
[operations guide](https://github.com/HelgeSverre/fsdb/blob/main/docs/operations.md)
describes the procedure.
