# Fsdb 0.1.4

This stable patch release improves correlated aggregate diagnostics and keeps
the .NET 10 F# library available separately from the MySQL-protocol CLI.

## Changes since 0.1.3

- Preserve MySQL 8.4's conversion-warning count for audited correlated
  nullable `COUNT` queries, including grouped and ordinary execution, `IN`
  candidates, and zero-row limits.
- Return a missing qualified aggregate-column error before evaluating a
  correlated numeric predicate. This covers `COUNT`, `COUNT(DISTINCT ...)`,
  `SUM`, and a derived source without a stray preceding warning.
- Avoid deriving the same grouped correlated count shape twice on the first
  eligible outer key.

The focused cases were compared with MySQL 8.4.11. The 3,947-test suite and
package consumer pass locally; the release workflow repeats these checks on
the tagged source. The indexed correlated `BETWEEN` warning count remains an
open diagnostics gap, recorded in `GAPS.md`. Broader compatibility gaps also
remain there.

For durable databases, back up a stopped data directory and test the new
version against a copy before upgrading. Cross-version migration and
downgrade compatibility are not yet guaranteed.
