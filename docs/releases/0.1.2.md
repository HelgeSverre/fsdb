# Fsdb 0.1.2

This stable patch release improves correlated counts, Japanese full-text
search, and joined-view write concurrency. It contains the .NET 10 F# library;
the MySQL-protocol CLI remains a separate project.

## Changes since 0.1.1

- Precompute correlated `COUNT(nullable_column)` over qualified physical
  columns using exact numeric join keys, while preserving SQL `NULL` counting.
  A MySQL 8.4.11 comparison and row-examination regression cover this path.
- Restore hiragana and katakana full-text token distinctions for the Japanese
  `utf8mb4_ja_0900_as_cs_ks` collation. Differential searches across ngram
  sizes 1–10 matched MySQL in the tested corpus.
- Joined-view updates now claim physical rows read through grouped and `UNION`
  derived sources. Concurrent changes to those sources are rechecked before
  the write, matching tested MySQL 8.4.11 cases.

These fixes cover the audited cases; other compatibility gaps remain in
`GAPS.md`.

For durable databases, back up a stopped data directory and test the new
version against a copy before upgrading. Cross-version migration and
downgrade compatibility are not yet guaranteed.
