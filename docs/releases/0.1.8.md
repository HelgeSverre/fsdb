# Fsdb 0.1.8

This stable patch release corrects geographic shared-endpoint topology in
the .NET 10 F# library and MySQL-protocol server.

## Changes since 0.1.7

- Classify exactly shared geographic segment endpoints before sampling long
  arcs, preventing spurious interior crossings.
- Match pinned MySQL 8.4.11 for the audited long-segment `ST_Intersects`,
  `ST_Crosses`, `ST_Touches`, and `ST_Distance` case in all four orientations.
- Restore the corresponding geographic polygon's `ST_IsValid` result.
- Add a reproducible, dependency-locked oracle probe and update the reviewed
  geographic mismatch ledger.

Validation includes all 3,955 tests, isolated package consumption, 1,000
shared-endpoint triples, and 3,000 global rings against pinned MySQL 8.4.11.
The ring corpus retains one known nonadjacent crossing discrepancy, including
its distance error. This release does not establish general geographic
intersection parity; remaining gaps are tracked in `GAPS.md`.

For durable databases, back up a stopped data directory and test the new
version against a copy before upgrading. Cross-version migration and
downgrade compatibility are not yet guaranteed.
