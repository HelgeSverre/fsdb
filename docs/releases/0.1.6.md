# Fsdb 0.1.6

This stable patch release improves nested writable views and correlated query
diagnostics in the .NET 10 F# library and MySQL-protocol server.

## Changes since 0.1.5

- Preserve logical `USING` join keys through successive expansions of nested
  writable views, including the audited joined-view case.
- Match MySQL's warning counts for scanned correlated `BETWEEN` expressions.
- Plan selective finite truncated `DOUBLE` ranges through an index and report
  range setup and candidate warnings for the audited direct-query cases.
- Audit CJK Extension A U+4700–U+49FF full-text ngram searches against pinned
  MySQL 8.4.11. The tested searches matched at ngram sizes 1 and 2.

Indexed correlated `BETWEEN` warning counts remain open and are recorded in
`GAPS.md`. The package checks and full test suite are run before tagging and
again by the release workflow.

For durable databases, back up a stopped data directory and test the new
version against a copy before upgrading. Cross-version migration and
downgrade compatibility are not yet guaranteed.
