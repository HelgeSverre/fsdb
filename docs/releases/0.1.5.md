# Fsdb 0.1.5

This stable patch release improves spatial predicate behavior and layered
updatable views in the .NET 10 F# library and MySQL-protocol server.

## Changes since 0.1.4

- Expose geographic polygon boundary-crossing events for the audited spatial
  predicate cases. The remaining geographic overlay cases are tracked in
  `GAPS.md`.
- Preserve logical NATURAL/USING join keys when an updatable nested view is
  expanded into physical joins. A window CTE can now follow a checked joined
  view in a writable outer view, matching MySQL 8.4.11 for metadata, updates,
  affected rows, and CHECK OPTION failures.

The focused view case was compared with pinned MySQL 8.4.11. The full test
suite and package consumer are checked before tagging and repeated in the
release workflow.

For durable databases, back up a stopped data directory and test the new
version against a copy before upgrading. Cross-version migration and
downgrade compatibility are not yet guaranteed.
