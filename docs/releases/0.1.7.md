# Fsdb 0.1.7

This stable patch release improves correlated range planning and diagnostics
in the .NET 10 F# library and MySQL-protocol server.

## Changes since 0.1.6

- Match pinned MySQL 8.4.11 warning counts for the audited indexed correlated
  DOUBLE BETWEEN cases, including repeated outer keys, empty results,
  empty tables, range setup, and candidate filtering.
- Honor correlated equality index hints and retain forced range access when
  the ordinary range-cost threshold would prefer a scan.
- Compare eligible ranges with estimated full-key owner-index cardinality,
  retaining distinct initial and refinement setup phases while preserving
  broad-candidate index intersections.
- Accept exactly representable integer, unsigned integer, and DECIMAL bounds
  as DOUBLE range cuts. Bounds that lose precision retain a conservative
  fallback.
- Suppress conversion diagnostics from outer LIMIT 0 metadata probes.
- Reduce avoidable allocations in numeric index probes and empty view-catalog
  lookups, and reuse immutable range selections across refinement phases.
- Add a regression confirming that an audited nested checked view LEFT JOINed
  to a window CTE remains read only, matching MySQL metadata and errors.

The correlated benchmark now exercises eligible numeric ranges; its earlier
failed-range-plan interpretation has been corrected in the reports. On that
eligible workload, the refinement reuse change improved median throughput
33.8% and reduced allocations 23.7% in its matched comparison. The selected
range path still has costs beyond the earlier equality fallback; these
measurements do not establish a general throughput improvement. See
`benchmarks/results/2026-11-17-eligible-range-reuse.md` for scope and evidence.

Broader optimizer statistics and cost parity, specialized correlated
intersections, and the other compatibility gaps remain tracked in `GAPS.md`.
The full suite and isolated package consumer are checked before tagging and
repeated by the publication workflow.

For durable databases, back up a stopped data directory and test the new
version against a copy before upgrading. Cross-version migration and
downgrade compatibility are not yet guaranteed.
