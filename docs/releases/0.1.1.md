# Fsdb 0.1.1

This patch release improves correlated aggregate execution and joined-view
concurrency. It contains the .NET 10 F# library; the MySQL-protocol CLI remains
a separate project.

## Changes since 0.1.0

- Precompute more correlated `COUNT` cases over non-null physical columns and
  cache the column-presence proof for the statement. The benchmark and MySQL
  differential results are in `benchmarks/results/2026-11-06-count-column-presence-cache.md`.
- Joined-view updates now claim physical read rows inside a grouped derived
  source. After a concurrent change to that source commits, the update
  reevaluates view membership before writing. A pinned MySQL 8.4.11 comparison
  and transaction regression cover the case.
- Add MySQL-checked regression coverage for `WITH CHECK OPTION` on a grouped
  `NATURAL JOIN` view.

The geographic line-relation differences documented after 0.1.0 remain open.
See `GAPS.md` for the current compatibility boundaries.

For durable databases, back up a stopped data directory and test the new
version against a copy before upgrading. Cross-version migration and
downgrade compatibility are not yet guaranteed.
