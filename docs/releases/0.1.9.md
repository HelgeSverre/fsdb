# Fsdb 0.1.9

This stable patch release improves geographic compatibility and reduces
allocations during indexed queries in the .NET 10 F# library and
MySQL-protocol server.

## Changes since 0.1.8

- Replace sampled long-edge geographic crossings with a Sjöberg intersection
  calculation, fixing the remaining audited crossing and its distance error.
- Support geographic `ST_IsValid` checks for polygon holes, multipolygons,
  and geometry collections, including polar cases and component contacts.
- Add reproducible adversarial geographic corpora checked against pinned
  MySQL 8.4.11, and update the remaining compatibility gaps.
- Compare indexed keys directly without constructing temporary zipped lists.
  The measured in-memory correlated-range workload allocated approximately
  11.6% fewer bytes per query; throughput measurements were noisy and do not
  establish a general performance improvement.

Validation includes all 3,957 tests, isolated package consumption, 5,845
geographic polygon comparisons across three seeds and three ellipsoids,
and 4,000 geographic control cases. The intersection fix also passed a
7,000-case oracle corpus. These checks cover the recorded cases, rather
than establishing full MySQL compatibility; remaining gaps are in `GAPS.md`.

For durable databases, back up a stopped data directory and test the new
version against a copy before upgrading. Cross-version migration and
downgrade compatibility are not yet guaranteed.
